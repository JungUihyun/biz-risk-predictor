# [기획서] 소상공인 맞춤형 상권 폐업 위험도 및 SHAP 원인 진단 웹 서비스

본 기획서는 데이터사이언스활용 강의의 개별 프로젝트 과제(비중 30%) 평가 기준과 주차별 일정에 맞춰 작성된 머신러닝 기반 웹 서비스 기획서입니다. 본 프로젝트는 공공 상권 데이터와 머신러닝 분류 알고리즘, 그리고 설명 가능 인공지능(XAI) 기술인 SHAP을 결합하여 소상공인 및 예비 창업자에게 데이터 기반의 상권 폐업 위험도 진단 및 원인 분석 리포트를 제공합니다.

## 1. 프로젝트 개요 및 추진 배경

### 1.1 프로젝트 정의
* **서비스명**: 소상공인 맞춤형 상권 폐업 위험도 & SHAP 원인 진단 웹 서비스 (SmartStore Risk Inspector)
* **핵심 타겟**: 예비 소상공인, 기존 자영업자, 상권 분석가
* **핵심 기능**: 사용자가 특정 지역(시군구/동)과 업종(음식점, 서비스업, 도소매업 등)을 선택하면, 해당 상권의 폐업 위험도(안정/보통/위험)를 예측하고, 예측 결과에 영향을 미친 주요 요인(유동인구, 동일업종 점포 수, 매출 변화율 등)을 SHAP(SHapley Additive exPlanations) 시각화 리포트로 제공합니다.

### 1.2 추진 배경 및 필요성
소상공인의 창업 후 3년 내 폐업률은 여전히 높은 수준을 기록하고 있으나, 기존의 상권 분석 서비스는 단순 수치나 통계 그래프 제공에 그쳐 자영업자가 스스로 대책을 세우기 어렵습니다. 본 프로젝트는 머신러닝 모델의 예측 결과와 함께 **"왜 그러한 위험도가 산출되었는지"**를 설명 가능 인공지능 기법으로 해명함으로써, 실제 자영업자가 행동할 수 있는 인사이트를 제공하고자 합니다.

## 2. 강의자료 핵심 개념 연계성 (Course Alignment)

본 프로젝트는 데이터사이언스활용 강의에서 강조하는 머신러닝 이론, 알고리즘 평가 지표, 파이썬 데이터 핸들링 메커니즘을 전 과정에 걸쳐 엄격하게 적용합니다.

### 2.1 3대 머신러닝 유형 적용: 분류 (Classification)
강의자료 OT에서 다루는 3가지 머신러닝 과제 유형(분류, 회귀, 군집화) 중 정답 레이블이 카테고리(범주)인 **분류(Classification) 문제**로 프로젝트를 정의합니다.
* **타겟 변수 (y)**: 상권의 폐업 위험 등급 (0: 정상/안정, 1: 고위험/폐업 우려)

### 2.2 분류 모델 및 하이퍼파라미터 튜닝
강의 4장의 핵심 알고리즘인 **결정 트리(Decision Tree)**와 앙상블 기법인 **랜덤 포레스트(RandomForestClassifier)**를 메인 모델로 채택합니다.
* **불순도 지표 (Impurity)**: 노드 분할 시 지니 계수(`Gini = 1 - sum(p_i^2)`)를 기반으로 불순도가 낮아지는 정보 이득(Information Gain)이 최대가 되는 피처와 임곗값을 선택합니다.
* **과적합(Overfitting) 방지**: 트리의 깊이가 무제한 커질 때 발생하는 과적합을 막기 위해 `max_depth`, `min_samples_split`, `min_samples_leaf` 하이퍼파라미터를 `GridSearchCV`로 교차 검증 및 튜닝합니다.
* **병렬 처리**: 대용량 상권 데이터를 빠르게 학습하기 위해 `n_jobs=-1`을 설정하여 멀티 코어 병렬 컴퓨팅을 수행합니다.

### 2.3 설명 가능 인공지능 (XAI: SHAP Value) 연계
강의 4장에서 다루는 **TreeSHAP (`shap.TreeExplainer`)**을 도입하여 머신러닝 모델의 블랙박스 특성을 해소합니다.
* 단순한 불순도 기반 `feature_importances_`가 가지는 한계(변수 간 상관관계에 따른 편향, 예측 방향성 미제공)를 극복하고, 개별 상권 샘플에 대한 예측 결과를 `예측값 = 기준값(Base Value) + SHAP 값의 합`으로 분해합니다.
* 이를 통해 "해당 지역은 동일 업종 점포 과밀(+0.18) 및 상권 매출 감소(+0.12)가 폐업 위험도를 높인 핵심 원인"임을 수학적 기여도로 명확히 보여줍니다.

### 2.4 파이썬 데이터 핸들링 (NumPy & Pandas)
* **NumPy 배열 구조 검증**: 강의 1-3장에서 강조하는 배열 Shape 검증 원칙을 준수합니다. 모델 학습 전 `X`는 2차원 `(n_samples, n_features)`, `y`는 1차원 `(n_samples,)`임을 확인하고, `assert X.shape[0] == y.shape[0]` 구문으로 차원 불일치 에러를 방지합니다. 또한 `dtype` 확인 및 `astype()` 변환으로 숫자가 문자열로 들어가는 문제를 정제합니다.
* **Pandas 결측치 및 슬라이싱**: 강의 1-4장의 API를 활용하여 공공 API 수집 데이터의 결손값(`NaN`)을 `isna().sum()`으로 파악하고 `fillna()`로 평균/중앙값 대체합니다. 명칭 기반 `loc[]` 및 위치 기반 `iloc[]` 연산자를 활용하여 피처 추출(`X = df.iloc[:, :-1]`, `y = df.iloc[:, -1]`)을 수행하며, `groupby().agg()`로 동별/업종별 집계 피처를 생성합니다.

### 3.1 데이터 수집 및 정제 파이프라인 코드 예시
공공 API 수집 데이터의 전처리 및 모델 입력을 위한 파이썬 정제 파이프라인 과정은 다음과 같습니다.

```python
import pandas as pd
import numpy as np

# 1. API 데이터 로드 및 결측치 검증
df = pd.read_csv('seoul_commercial_district.csv')
print("결측치 현황:\n", df.isna().sum())

# 2. 결측치 대체 (fillna) 및 피처 생성
df['monthly_sales'] = df.groupby('dong_code')['monthly_sales'].transform(lambda x: x.fillna(x.mean()))
df['floating_pop'] = df['floating_pop'].fillna(df['floating_pop'].median())

# 3. Target 변수 설정 (폐업률 상위 30% = 고위험 1, 나머지 0)
df['risk_label'] = (df['close_rate'] >= df['close_rate'].quantile(0.7)).astype(int)

# 4. iloc 기반 X, y 분리 (강의자료 연계)
X_df = df[['store_count', 'open_rate', 'close_rate', 'monthly_sales', 'floating_pop']]
y_series = df['risk_label']

X = X_df.values
y = y_series.values

# 5. NumPy Shape 및 Assert 검증 (강의자료 연계)
print(f"X shape: {X.shape} (dtype: {X.dtype})")
print(f"y shape: {y.shape} (dtype: {y.dtype})")
assert X.shape[0] == y.shape[0], "X와 y의 행 개수가 일치하지 않습니다."
```

## 4. 시스템 아키텍처 및 기술 스택

### 4.1 Next.js 스택 선택 이유
Streamlit은 빠른 프로토타이핑에 유리하지만, UI 커스터마이징과 차트 애니메이션, 모바일 반응형 웹 구현에 한계가 있습니다. 반면 Next.js는 다음과 같은 장점이 있어 한층 효율적입니다.
* **App Router & Server Components**: 기본 상권 데이터는 서버 사이드 렌더링(SSR/SSG)으로 빠르게 로딩하고, 클라이언트 단에서는 Recharts와 Tailwind CSS로 매끄러운 대시보드를 제공합니다.
* **API Routes 제공**: 별도의 복잡한 백엔드 없이 Next.js 자체 API Routes에서 Python 백엔드 API와 통신하여 데이터를 처리할 수 있습니다.

## 6. 핵심 기능 및 UI/UX 화면 구성안

1. **대시보드 메인 화면**:

   * **SHAP Waterfall Plot 시각화**: 위험도를 상승시킨 주요 피처(+방향, 빨간색)와 완화시킨 피처(-방향, 파란색)를 대시보드 그래프로 표현.
3. **맞춤형 컨설팅 보고서**:
   * "현재 상권은 유동인구 대비 동일 업종 점포 수가 과밀 상태입니다. 배달 서비스 비중 확대 및 마케팅 강화가 필요합니다."와 같은 AI 진단 가이드 텍스트 제공.
