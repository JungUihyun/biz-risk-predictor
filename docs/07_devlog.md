## 2026-10-14 · 중간 발표 피드백

### 교수님 보완 사항
> **분기별 GDP 같은 거시경제 데이터를 붙이면 폐업 위기를 예측하는 데 더 도움이 될 것.**

### 왜 도움이 되나
- 지금 피처는 모두 **상권 내부 지표**(점포·매출·유동인구)뿐이라, 경기 전체가 나빠져서 폐업이 늘어나는 **외부 충격**을 모델이 볼 수 없음
- 같은 상권이라도 경기 하강기에는 폐업이 늘어나므로, 거시 지표가 **분기별 기본 위험 수준**을 설명해 줄 수 있음

### 후보 데이터 (분기 단위로 맞춰 결합)
| 지표 | 출처 (확인 필요) | 주기 | 비고 |
| --- | --- | --- | --- |
| 실질 GDP 성장률 (전기 대비) | 한국은행 ECOS Open API | 분기 | 교수님이 언급하신 지표 |
| 민간소비 증감률 | 한국은행 ECOS | 분기 | 자영업 매출과 직접 관련 |
| 기준금리 | 한국은행 ECOS | 수시 → 분기말 값 | 대출 이자 부담 |
| 소비자심리지수 (CCSI) | 한국은행 ECOS | 월 → 분기 평균 | 체감 경기 |
| 소비자물가지수 (CPI) 상승률 | 통계청 KOSIS | 월 → 분기 평균 | 원가·임대료 부담 |
| 서울 서비스업생산지수 · 소매판매액지수 | 통계청 KOSIS (시도별) | 분기 | **서울 지역** 경기라 더 직접적, 제공 여부 확인 필요 |

- 결합 키: `STDR_YYQU_CD`(기준 분기) — 같은 분기의 모든 행정동·업종에 같은 값이 붙음

### 적용할 때 주의할 점
1. **정보량이 적음**: 거시 지표는 분기마다 값이 하나뿐(22개 분기)이라, 모든 상권에 같은 값이 들어감 → 수준값보다 **전 분기 대비 / 전년 동기 대비 변화율**을 쓰고, **업종 대분류와 결합**(예: 외식업 × 민간소비 증감)해 업종별로 다르게 작용하도록 함
2. **시점 원칙 유지**: t분기 거시 지표 → t+1분기 폐업 위험. GDP 속보치는 분기 종료 후 약 1개월 뒤 발표되므로, 실제 서비스에서는 **발표된 값만** 쓰도록 시차 고려
3. **시간 분할과의 충돌**: 테스트 기간(2025Q2~2026Q1)의 거시 값이 학습 기간 범위를 벗어나면 트리 모델은 외삽을 못 함 → 변화율·순위 형태로 변환해 완화
4. **효과 검증**: 거시 지표 **추가 전/후**를 같은 시간 분할에서 Test AUC · Recall · F1로 비교(ablation)해 실제로 도움이 되는지 확인
