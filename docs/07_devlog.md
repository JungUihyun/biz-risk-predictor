### 트러블슈팅
- **Next.js 16 `cacheComponents`**: `/api/options` Route Handler가 빌드할 때 정적으로 굳어 버리는 문제가 있었습니다 → `await connection()`으로 요청 시점에 실행되도록 고쳤습니다.
- **`useSearchParams`**: 진단 페이지를 `<Suspense>`로 감싸서 정적 셸과 분리했습니다.
- **SHAP 출력 형태**: shap 버전에 따라 이진 분류 결과가 `list[2]` 또는 `(n, f, 2)` 배열로 나옵니다 → 양성 클래스 기준으로 통일하는 함수를 만들었습니다.

### 트러블슈팅
- **matplotlib 한글 폰트**: AppleGothic에 유니코드 마이너스(−) 글리프가 없어서 SHAP waterfall의 음수가 □로 깨졌습니다 → `font.family = ["AppleGothic", "DejaVu Sans"]`로 대체 폰트를 지정했습니다.

- **iCloud 저장 공간 최적화로 실행이 멈춤**: 프로젝트를 `~/Documents`(iCloud 데스크탑 및 문서 동기화)로 옮긴 뒤 몇 시간 만에 `.venv`(6,302개)와 `node_modules`(2,651개) 파일이 *dataless* 상태(클라우드에만 있고 로컬은 빈 상태)가 되었습니다. 그래서 `import urllib3` 단계에서 수집 스크립트가 멈췄습니다.
  - 진단: `faulthandler.dump_traceback_later`로 멈춘 위치 확인 → `find .venv -flags +dataless`로 원인 확정
  - 해결: 가상환경을 `.venv.nosync`(iCloud 제외)로 다시 만들고 `.venv` 심볼릭 링크를 둠
  - `node_modules`를 심볼릭 링크로 바꾸면 Turbopack이 `Module not found`를 냄 → 실제 폴더를 유지하고 `com.apple.fileprovider.ignore#P` 확장 속성으로 동기화에서 제외
