### Slide 5. 문제 정의: 분류 + 데이터 누수 방지
- y = **다음 분기** 폐업률이 업종 대분류 내 상위 30% → 1
- X = **이번 분기** 지표 16개
- 그림: 시간축 다이어그램 `t분기 피처 → t+1분기 레이블`
- ❌ 같은 분기 폐업률로 레이블과 피처를 함께 만들면 정답을 보고 맞히는 꼴 → 의미 없는 100%

> 🎤 "기획 초안에서 제가 실수한 부분입니다. 같은 분기 폐업률을 피처와 정답에 동시에 쓰면 모델이 정답을 보고 맞히게 됩니다. 그래서 다음 분기를 예측하는 구조로 바꿨습니다."  ← 이 슬라이드가 발표의 핵심 포인트

### Slide 6. 피처 설계
- 점포: 점포 수, 유사업종 점포 수, 프랜차이즈 비율, 개업률, 현재 폐업률, 점포 증감률
- 매출: 매출액, 점포당 매출, 매출 증감률, 주말 매출 비중
- 유동인구: 유동인구, **점포당 유동인구(과밀도)**, 주말 비중
- 업종: 외식/서비스/소매 원-핫

### Slide 7. 강의 내용 연계
| 강의 | 적용 |
| --- | --- |
| NumPy | X·y Shape/dtype assert 검증 |
| Pandas | isna → groupby.transform(fillna), 증감률 파생 |
| 결정 트리 | 지니 불순도, max_depth·min_samples 튜닝 |
| 랜덤 포레스트 | n_jobs=-1 병렬, GridSearchCV 5-fold |
| SHAP | TreeExplainer, 기준값 + ΣSHAP = 예측값 검증 |

### Slide 8. 시스템 아키텍처
- 다이어그램: 수집 → 전처리 → 학습 → artifacts → FastAPI ← Next.js(Vercel)
- 기술: Python, scikit-learn, SHAP, FastAPI / Next.js 16, Tailwind, Recharts
- 배포: Vercel + Heroku(Student Pack) + Namecheap 도메인 → **운영비 $0**

### Slide 9. EDA에서 발견한 것
- 점포 5개 이상 조합의 **65.8%는 폐업률 0** → 레이블 임곗값: 외식 6%, 서비스·소매 1%
- 100개 업종 중 **37개는 추정매출이 아예 없음** (변호사·세무사 사무소, 독서실 등) → `has_sales` 피처 추가
- 외식업 매출 제공률 96%, 서비스 62%, 소매 68%

### Slide 9-2. 1차 모델 결과 (실데이터)
| 모델 | Test AUC | Recall | F1 |
| --- | --- | --- | --- |
| 베이스라인 (현재 폐업률만) | 0.558 | – | – |
| Decision Tree | 0.722 | 0.264 | 0.361 |
| **Random Forest** | **0.734** | **0.627** | **0.520** |
- 학습 2021Q1~2025Q1 → 테스트 2025Q2~2026Q1 (미래 분기로 평가), CV AUC 0.736 ≈ Test 0.734
- 그림: `images/shap_beeswarm.png` — 상위 요인: 유사업종 점포 수, 점포 수, 개업률, 업종, 점포당 유동인구

> 🎤 "단순 규칙보다 AUC가 0.18 높고, 미래 분기에서도 성능이 유지됩니다. 다만 점포 수가 가장 큰 요인으로 나온 것은 '폐업 1건 이상'이라는 레이블 때문에 생긴 편향일 수 있어서, 다음 단계에서 레이블을 다시 설계할 계획입니다."  ← 한계를 먼저 말하는 것이 신뢰도에 좋음

## 예상 질문 & 답변

| 질문 | 답변 |
| --- | --- |
| 왜 회귀(폐업률 예측)가 아니라 분류인가? | 사용자에게 필요한 것은 정확한 %보다 "위험한지 아닌지"입니다. 또 동·업종별 폐업률은 노이즈가 커서 등급으로 바꾸는 쪽이 안정적입니다. 회귀는 비교 실험으로 추가할 수 있습니다. |
| 상위 30% 기준의 근거는? | 클래스 불균형을 적당히 유지하는 실용적인 선택입니다. 실데이터 분포를 본 뒤 20/30/40%로 민감도 분석을 할 예정입니다. |
| 무작위 분할을 안 한 이유? | 같은 동·업종의 미래 분기가 학습에 섞이면 성능이 부풀려집니다. 실제 사용 상황처럼 과거로 학습하고 미래로 평가했습니다. |
| SHAP이 feature_importances_보다 나은 점? | 개별 예측 단위로 설명할 수 있고, 영향의 방향(±)을 알려주며, 기여도의 합이 예측값과 정확히 일치합니다. |
| AUC 0.73이면 충분한가? | 상권 폐업은 임대료나 개인 사정처럼 데이터에 없는 요인이 많아서 높은 정확도를 기대하기 어렵습니다. 그래서 단순 베이스라인(0.558) 대비 개선폭과 시간에 따른 안정성(CV 0.736 ≈ Test 0.734)을 기준으로 평가했습니다. |
| 화면의 66%가 실제 폐업 확률인가? | 아닙니다. class_weight=balanced로 학습해서 확률이 높게 나옵니다. 지금은 상대적 위험 점수로 쓰고, 확률 보정은 다음 단계 과제입니다. |
