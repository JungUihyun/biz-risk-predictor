### Slide 1. 표지
- **Biz Risk Predictor**
- 서울시 상권 폐업 위험도 예측 및 SHAP 원인 진단 웹 서비스
- 데이터사이언스활용 개별 프로젝트 · 이름 / 학번

### Slide 2. 문제 제기
- 소상공인의 창업 후 3년 내 폐업률은 여전히 높음
- 기존 상권 분석 서비스는 **통계를 보여줄 뿐, 해석은 사용자 몫**
- 질문: *"이 동네에서 이 업종, 다음 분기에 위험할까? **왜?**"*

### Slide 5. 문제 정의: 분류 + 데이터 누수 방지
- y = **다음 분기** 폐업률이 업종 대분류 내 상위 30% → 1
- X = **이번 분기** 지표 17개
- 그림: 시간축 다이어그램 `t분기 피처 → t+1분기 레이블`
- ❌ 같은 분기 폐업률로 레이블과 피처를 함께 만들면 정답을 보고 맞히는 꼴 → 의미 없는 100%

### Slide 6. 피처 설계
- 점포: 점포 수, 유사업종 점포 수, 프랜차이즈 비율, 개업률, 현재 폐업률, 점포 증감률
- 매출: 매출액, 점포당 매출, 매출 증감률, 주말 매출 비중, 매출 제공 여부
- 유동인구: 유동인구, **점포당 유동인구(과밀도)**, 주말 비중
- 업종: 외식/서비스/소매 원-핫

### Slide 7. 강의 내용 연계
| 강의 | 적용 |
| --- | --- |
| NumPy | X·y Shape/dtype assert 검증 |
| Pandas | isna → groupby.transform(fillna), 증감률 파생 |
| 결정 트리 | 지니 불순도, max_depth·min_samples 튜닝 |
| 랜덤 포레스트 | n_jobs=-1 병렬, GridSearchCV 5-fold |
| SHAP | TreeExplainer, 기준값 + ΣSHAP = 예측값 검증 |

### Slide 8. 시스템 아키텍처
- 다이어그램: 수집 → 전처리 → 학습 → artifacts → FastAPI ← Next.js(Vercel)
- 기술: Python, scikit-learn, SHAP, FastAPI / Next.js 16, Tailwind, Recharts
- 배포: Vercel + Heroku(Student Pack) + Namecheap 도메인 → **운영비 $0**

### Slide 9. EDA에서 발견한 것
- 점포 5개 이상 조합의 **65.8%는 폐업률 0** → 레이블 임곗값: 외식 6%, 서비스·소매 1%
- 100개 업종 중 **37개는 추정매출이 아예 없음** (변호사·세무사 사무소, 독서실 등) → `has_sales` 피처 추가
- 외식업 매출 제공률 96%, 서비스 62%, 소매 68%

### Slide 9-2. 1차 모델 결과 (실데이터)
| 모델 | Test AUC | Recall | F1 |
| --- | --- | --- | --- |
| 베이스라인 (현재 폐업률만) | 0.558 | – | – |
| Decision Tree | 0.722 | 0.264 | 0.361 |
| **Random Forest** | **0.734** | **0.627** | **0.520** |
- 학습 2021Q1~2025Q1 → 테스트 2025Q2~2026Q1 (미래 분기로 평가), CV AUC 0.736 ≈ Test 0.734
- 그림: `images/shap_beeswarm.png` — 상위 요인: 유사업종 점포 수, 점포 수, 개업률, 업종, 점포당 유동인구

### Slide 10. 진단 화면 시연
